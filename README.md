# Local AI Intelligence Workbench

A privacy-focused, locally running AI assistant that lets you upload documents and ask questions about their contents. It uses semantic search and a local language model to generate answers grounded in your documents.

## Features

- **Document Upload:** Upload PDF and TXT files through a web interface.
- **Document Processing:** Extract text and split it into smaller chunks for retrieval.
- **Semantic Search:** Generate embeddings and retrieve relevant document content using vector similarity search.
- **Local AI Chat:** Ask questions and receive answers generated by a locally running language model.
- **Source References:** View document sources used to support answers.
- **Conversation Storage:** Store conversations and messages in PostgreSQL.
- **Local-First Privacy:** Process documents and run AI inference locally using Ollama.

## Architecture

1. The user uploads a PDF or TXT document through the React frontend.
2. FastAPI receives the document and extracts its text.
3. The text is split into chunks.
4. Ollama generates embeddings for the chunks.
5. PostgreSQL stores document metadata, chunks, and vector embeddings.
6. When a user asks a question, the backend retrieves relevant chunks using semantic search.
7. The local language model generates an answer using the retrieved context.
8. The frontend displays the answer and its sources.

## Prerequisites

Install the following before running the project:

- Python 3.12+
- Node.js and npm
- PostgreSQL with the pgvector extension
- Ollama

## Local Setup

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
cd local-ai-workbench
```

### 2. Set up PostgreSQL

Create a PostgreSQL database named `local_ai_workbench` and enable pgvector in that database:

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

Make sure PostgreSQL is running and the database is accessible from your machine.

### 3. Configure the backend

Navigate to the backend directory:

```bash
cd backend
```

Create and activate a Python virtual environment if one does not already exist:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the backend dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file in the `backend/` directory with your local configuration:

```env
APP_NAME="Local AI Intelligence Workbench"
DATABASE_URL="postgresql+psycopg://localhost:5432/local_ai_workbench"
OLLAMA_BASE_URL="http://localhost:11434"
CHAT_MODEL="llama3.2"
EMBEDDING_MODEL="nomic-embed-text"
```
